# B站 Cookie 获取详细指南

## 为什么需要 SESSDATA？

B站视频如果没有 CC 字幕，需要用户登录后才能获取 AI 生成的字幕。SESSDATA 是 B站的会话 cookie，用于验证用户身份。

## 获取步骤

### 方法一：Chrome/Edge 浏览器（推荐）

1. 使用 Chrome 或 Edge 浏览器打开 B站并**登录账号**
2. 按 `F12` 打开开发者工具
3. 点击顶部 `Application` 标签页
4. 在左侧边栏展开 `Cookies` → 点击 `https://www.bilibili.com`
5. 在右侧列表中找到 `SESSDATA` 这一行
6. 复制 `Value` 列的完整值（一串很长的字符）
7. 将该值提供给 Claude

### 方法二：Firefox 浏览器

1. 打开 B站并登录
2. 按 `F12` 打开开发者工具
3. 点击 `存储` 标签
4. 展开 `Cookie` → 选择 `https://www.bilibili.com`
5. 找到 `SESSDATA`，复制其值

## 使用 SESSDATA

skill 会自动将 SESSDATA 转换为标准 Netscape 格式的 cookies.txt 文件：

```bash
# 自动生成 cookies.txt
cat > cookies.txt << EOF
# Netscape HTTP Cookie File
# This file was generated by video-to-article skill
.bilibili.com	TRUE	/	TRUE	1791183873	SESSDATA	${USER_SESSDATA}
EOF
```

## 注意事项

- ⚠️ **SESSDATA 包含账号敏感信息，请勿泄露给他人**
- ⏰ SESSDATA 有时效性（通常几个月），过期后需要重新获取
- 🤖 AI 生成的字幕质量可能不如人工字幕，但内容完整性更好
- 💾 cookies.txt 文件会保留在工作目录，下次使用时可能仍然有效
- 🔒 建议定期更换密码后重新获取 SESSDATA

## 故障排除

### 问题 1：Cookie 文件格式错误

```bash
# 检查 cookie 文件格式
cat cookies.txt

# 确保格式为：
# .bilibili.com	TRUE	/	TRUE	过期时间	SESSDATA	值
```

### 问题 2：Cookie 已过期

症状：提示"需要登录"或"权限不足"

解决：重新登录 B站，获取新的 SESSDATA

### 问题 3：仍然无法下载字幕

```bash
# 测试 cookie 是否有效
yt-dlp --cookies cookies.txt --list-subs "B站视频链接"

# 尝试使用 --no-check-certificate
yt-dlp --no-check-certificate --cookies cookies.txt --list-subs "视频链接"
```

## 支持的字幕类型

| 字幕类型 | 说明 | 需要 Cookie |
|---------|------|------------|
| CC 字幕 | UP主上传的人工字幕 | ❌ 不需要 |
| AI 字幕 | B站自动生成的字幕 | ✅ 需要 |

## 命令示例

### 下载 CC 字幕（无需 Cookie）
```bash
yt-dlp --write-subs --sub-lang zh-Hans --skip-download "B站视频链接"
```

### 下载 AI 字幕（需要 Cookie）
```bash
yt-dlp --write-auto-subs --sub-lang zh-Hans --skip-download --cookies cookies.txt "B站视频链接"
```

### 同时尝试两种字幕
```bash
yt-dlp --write-subs --write-auto-subs --sub-lang zh-Hans --skip-download --cookies cookies.txt "B站视频链接"
```
